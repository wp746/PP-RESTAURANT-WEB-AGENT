# PP 设计智能体外部参考调用 SOP v1.0

## 触发条件

用户要求设计**任何类型的网站**（餐饮、烘焙、茶饮、咖啡、酒店、展览、SaaS、教育、个人作品集、商业服务等），先读取本参考库，再按照项目需求访问可用站点，挑出真正匹配的元素。**不要求机械访问全部 25 站**，避免干扰创意。每个站点的可访问性、收费和版本会变化。

## P0｜收集项目输入

必填：项目名称、业务/品类、目标用户、内容素材、网站核心目的、预期交付（静态/框架/上线）、目标设备。

加分：品牌故事、实拍门店/产品图、Logo/VI、用户行为、参考禁忌、动效容忍度、国内网络条件。

缺失数据：列出“已证实／推断／演示／缺失”。不得用 AI 生成的设计概念冒充企业事实。

## P1｜先提炼品牌/内容 DNA（决定文化与信息）

提取：
1. 文化母题（历史事实、地域传统、技艺、价值主张或产品理念）
2. 三组情绪词（如：江湖热烈/温暖手作/城市冷静）
3. 最值得被看见的主对象（招牌锅、面包剖面、空间、人物、技术演示）
4. 顾客进入网站的前三个问题
5. 页面能否从素材中自洽地讲清故事

## P2｜参考库定向检索

按照**设计问题**选择站点，不是随机看图：

- 需要文化叙事/高级站点整体气质：Minimal Gallery → Kage → Refero Styles
- 需要设计令牌/可复用字体与色彩：DESIGNmd → Refero Styles → 乔木字体仓库
- 需要首屏/专题架构：Jiro → VibePrompt → 21st.dev / Aceternity
- 需要标准可读交互组件：Component Gallery → shadcn/ui → UIAble
- 需要操作反馈、Tab、按钮：MicroKit → Uiverse → Kinetics
- 需要高质量适度动画：Motion Primitives → Anime.js → CSS Text Effects
- 需要地图/到店：mapcn 仅做组件参考；国内静态站优先 `https://uri.amap.com/` 等确认过的外部导航链路
- 需要插画/IP：Kitbitz → 3dicons；核对类别和授权，避免拼贴碎片感
- 需要手机展示：AppShot Gallery；借视觉层级而非直接复刻 App 页面
- 需要加载状态：Circle Loaders；不应让装饰性预加载阻塞页面
- 需要玻璃/渐变：Liquid Glass（未核验）/ Gradient Buttons；极少量慎用

**输出《参考拆解卡》**，每个入选参考至少写清：①URL ②要借的抽象规则 ③不适配或危险部分 ④如何转成该项目自己的设计 ⑤实现策略 ⑥授权来源。

## P3｜原创设计概念与视觉导演

每次至少想 2–3 种内部备选艺术方向，但**最终交付 1 个完整融合版本**（除非用户要求多版）。

决定：主视觉隐喻、内容阅读顺序、网格、图像 crop 策略、色彩关系（主色/辅助/强调/中性色）、4 级字体角色、标题字是否需要 PNG/SVG、点缀元素的文化依据。

审查：每个装饰是否能解释其与品牌相关的含义；不能就删掉。

## P4｜交互按行业定制

餐饮：口味、人数、菜品配对、食材说明、吃法建议、导航；
烘焙：口感/保存/过敏原说明/产品图鉴；
酒店：房型/设施/照片分组与位置；
SaaS：功能故事、示例任务、定价与引导；
文化展览：时间线、作品导览、场馆路径；
服务企业：服务对比、案例、咨询入口。

要求所有点击有可观察响应；触摸与键盘能操作；弹层可以关闭；`prefers-reduced-motion` 降级。

## P5｜实现与兼容

**首选**：HTML/CSS/Vanilla JS 静态项目，图像、JS、CSS、字体本地化。复杂组件可用 React + 构建工具，但最终交付 `dist/` 纯静态文件（前提是无需服务器运行）。

禁止：未经用户许可添加付费 API、数据库、后端托管、追踪 SDK；不能在静态页面伪装已提交后台订单或真的完成预约。地图根据实际目标网络使用可靠链接。

## P6｜验收闸门

1. **文化真实性**：没有虚构创始年份、供应链、店史、评价；演示资料清晰标注。
2. **视觉质量**：字体品牌化、实拍照片/视觉资产不裁断主体、色彩符合品类、层次与节奏。
3. **交互有效**：导航、选项、弹层、CTA、禁用态、悬停与触摸可用。
4. **信息完整**：价格、品名、地址、营业时间、电话、过敏原等按素材状态显示，不凭空补真实信息。
5. **工程完整**：360/390/768/1440px 无横向溢出；CSS/JS 图片正确加载；国内弱网静态资源有降级；无未授权资源依赖。
6. **上线规范**：根目录必须有 `index.html`，门店分目录、相对路径一致；下载完整 ZIP；浏览器截图验收；用户确认后发布。

## 强制不做

- 不固定“所有餐饮都用书法、深黑、米白”的模板。
- 不把参考网页的截图、Logo、原始商业摄影直接放进新客户网站。
- 不把效果库中十几个复杂动画堆叠到同一页。
- 不因为来源是 React/Tailwind 就声称 ZIP HTML 可直接工作。
- 不直接使用不稳定境外 CDN 作为国内顾客访问的必要依赖。
- 不因 AI 输出“字体”就忽略汉字缺字和 LICENSE。
- 不把参考清单当作已下载、可再分发的资产包。
