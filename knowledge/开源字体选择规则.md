## 原始仓库
- GitHub：[joeseesun/qiaomu-cover-fonts](https://github.com/joeseesun/qiaomu-cover-fonts)
- 已检查 `README.md`、仓库目录；README 声明 **中文 19 款、英文 15 款，共 34 款、约 30.7 MB**，提供 12 套搭配，字体文件、授权文本和 index.json 索引。
- 仓库说明默认字库以 **SIL Open Font License 1.1** 分发；但混合来源字库实际应用必须核验单字体许可证及**保留字体名称（Reserved Font Names）**。
- 不要把“整个仓库所有字体一把塞进页面”：中文字体文件大，过量装载会让内地顾客首屏长时间空白；推荐每站 1 款展示、1 款正文、1 款英数，按需载入少数字重。

## 书法字与 PNG / WebP 资产

- 若主标题与品牌气质匹配，可做**原创手写字或用合法字体进行品牌化排版**，输出透明背景 PNG/WebP，最好同时保留 SVG（有许可且合适）和可访问的文字备用层。
- 不能把某个品牌的 Logo/书法商标搬到别家网站；不能把他人的字体略微变形就宣称具有独立版权。
- 关键文案在图片外仍应提供真实文本（语义标题/替代文字），利于屏幕阅读器与搜索理解。
- 使用书法字体前要检查汉字是否存在、字形是否清楚，手机端不可将图片压得不可读。

## Cloudflare Pages 字体技术规范

- 字体资源随站点一起上传，例如 `assets/fonts/display.woff2`；不是必须依赖外部 CDN。
- `@font-face` 指向同源 URL；设置 `font-display: swap`，正文 fallback 依品牌类别选用系统 sans-serif / serif。
- 推荐仅预加载首屏不可缺少的展示字重；首屏字体过大时改用透明 PNG/WebP 标题字 + 小体积正文方案。
- 站点打包保留字体 LICENSE/OFL 文本和相关版权说明；子集化、修改名、替换字体时核对 Reserved Font Names。
- 示例：

```css
@font-face {
  font-family: 'PPDisplay';
  src: url('/assets/fonts/display.woff2') format('woff2');
  font-style: normal;
  font-weight: 400;
  font-display: swap;
}
.brand-title { font-family: 'PPDisplay', 'Noto Serif SC', serif; }
```

**注意**：字体仓库官方说明曾针对字库进行子集化并提供许可。我们只保存核验结论和字体搭配索引，**本包不分发字体二进制文件**。正式项目需要下载所选字体并核查仓库许可文本。
