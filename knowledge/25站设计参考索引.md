# PP Web Design Reference Library v1.0

> 网页设计外部参考知识库（跨行业）  
> 编制日期：2026-10-10  
> 输入依据：用户提供的 25 个站点截图与 GitHub 仓库；本轮对官网/文档/公开检索进行抽样核验。  
> 定位：**创意来源导航 + 检索规则 + 设计落地约束**；不是已下载全部站点素材，也不是获取了全部商用许可。

## 总原则

- **先研究项目、再找参考**：为真实项目提取文化与商业目标、品类、消费场景、客群、影像质量；借参考库寻找表达方式，不让参考站点反过来决定品牌定位。
- **文化第一，视觉第二，交互第三，展示第四**：餐饮项目按这一设计优先级；非餐饮项目仍先确定品牌叙事/核心信息再构成体验。
- **元素级借鉴，不复制品牌**：拆成网格比例、字阶、动效时间曲线、交互状态、图片切换逻辑、色彩关系，再针对目标项目重构。
- **不套行业模板**：烘焙/茶饮/火锅/精品咖啡/酒店/科技工具不共用同一视觉语言。
- **兼容 Cloudflare Pages 免费静态托管**：输出静态 HTML/CSS/JS/图片/字体，或经构建后输出静态 `dist/`；需要后端、数据库或商业 API 的组件必须重设计或降级。
- **分清参考与复用许可**：截图参考≠原图可复制；代码许可证≠页面影像/品牌/IP 授权；字体免费商用≠允许打包转发。具体代码和资源要逐条核对。
- **国内弱网优先**：不把 Google Fonts CDN、GitHub raw、第三方地图瓦片作为关键首屏依赖；字体、菜品、主视觉尽量本地同域托管。

### 每站特别提醒与使用方式

**01 · Jiro Build** — 页面与区块提示词库；参考 Hero、分区节奏、组件组合。  
可借鉴：首屏结构、区块布局、文案层级、提示词。  
注意：部分条目为付费；提示词不是授权图片与源码。

**02 · Minimal Gallery** — 精选真实站点；重点检索 Food & drink、Branding、Editorial、Architecture、Photography。  
可借鉴：气质、字体、留白、影像叙事、网格。  
注意：参考第三方站点的构图规律，不搬运原图或品牌素材。

**03 · Kage** — 真实产品的界面、Hero、Gallery、Tab 和风格标签可组合搜索。  
可借鉴：真实UI、导航、Hero、卡片、编辑排版。  
注意：部分案例偏科技产品，需要品类适配。

**04 · Refero Styles** — DESIGN.md 风格参考；提取字体、色彩、间距、组件语法。  
可借鉴：设计令牌、网格、字阶、风格语言。  
注意：仅把样式作为启发；不要直接挪用第三方标识。

**05 · Component Gallery** — 对照 Carousel、Tabs、Accordion、Popover、Pagination 等标准交互模式。  
可借鉴：交互结构、可访问性、组件状态。  
注意：侧重交互设计范式，非完整视觉模板。

**06 · AppShot Gallery** — 真实 App 截图的视觉叙事、首屏信息权重与移动卡片设计。  
可借鉴：移动首屏、分镜、视觉层级、APP UI。  
注意：主要是 App Store 截图/营销视觉，不能直接等同网页交互。

**07 · DESIGNmd** — 以 DESIGN.md 表达颜色、字阶、留白、组件、Do/Don’t。  
可借鉴：DESIGN.md、Design Tokens、标准化。  
注意：标准参考；项目实际规则需重新推导。

**08 · VibePrompt** — Hero、Bento、CTA、导航、内容区等提示词结构。  
可借鉴：布局描述、Prompt、区块。  
注意：不是可直接复制的商用品牌设计。

**09 · 21st.dev** — 丰富的 React UI 与网页区块参考。  
可借鉴：Hero、Card、Tabs、Motion、组件。  
注意：React 代码需构建；静态单文件需改写。

**10 · Kinetics** — 弹簧物理动效与具有触感的状态变化。  
可借鉴：弹性、转场、细节动效。  
注意：移动端控制性能和眩晕；尊重 reduced-motion。

**11 · shadcn/ui** — 可访问、可定制组件的结构与状态参考。  
可借鉴：表单、弹窗、菜单、导航、卡片。  
注意：主要适用 React/Tailwind；无需全站引入以免臃肿。

**12 · Aceternity UI** — 背景、滚动层次、Hero 与高冲击区块。  
可借鉴：Hero、Scroll、视觉动效、背景。  
注意：某些组件收费或需 React/Motion；避免装饰过度。

**13 · Magic UI** — 交互反馈、文本/容器效果的视觉参照。  
可借鉴：动效、精致细节、交互。  
注意：需复核组件具体授权/代码依赖。

**14 · Motion Primitives** — 滚动出现、文字切入、布局转场与低干扰动效。  
可借鉴：文字动效、布局转场、微动画。  
注意：主要基于 React/Motion/Tailwind；Pro 为收费产品。

**15 · Uiverse** — 按钮、输入框、开关、卡片、加载状态的可复用细节。  
可借鉴：CSS、按钮、悬停、微交互。  
注意：官网声明站内 UI 元素 MIT；复用时保留许可要求。

**16 · UIAble** — 围绕 shadcn 生态的表单、表格、组件一致性。  
可借鉴：组件规范、表单、布局、一致性。  
注意：核对具体组件是否收费与许可。

**17 · mapcn** — MapLibre + React 地图的标注、线路与弹层设计。  
可借鉴：地图、Marker、Route、Popup。  
注意：地图实时服务依赖网络及瓦片源；静态门店站优先直接调用地图导航链接。

**18 · MicroKit UI** — 按钮反馈、Tab 切换、导航指示、输入聚焦。  
可借鉴：CSS、微交互、Tabs、Focus。  
注意：含 CSS 与 React 方案；官网称代码 MIT，按个别组件校验。

**19 · Liquid Glass** — 玻璃折射、半透明模糊与背景层次的效果候选。  
可借鉴：玻璃、折射、半透明。  
注意：本次页面无法访问核验，授权与具体实现不明；不得直接拷代码。

**20 · CSS Text Effects** — 字形出现、轮廓、文字运动的参考。  
可借鉴：文字特效、标题、字幕。  
注意：中文渲染、移动性能、无障碍降级要额外测试。

**21 · Circle Loaders** — 无依赖 SVG 圆形加载反馈；动画节奏和色彩可调整。  
可借鉴：Loading、SVG、状态反馈。  
注意：轻静态展示网站加载器不应拖慢内容出现；复用前确认许可。

**22 · Gradient Buttons** — 渐变 CTA、悬停反馈等按钮实验。  
可借鉴：Button、Gradient、Hover。  
注意：不应整站滥用渐变；文本可读性优先。

**23 · Kitbitz** — 手绘 SVG/PNG 世界观元素；适用于文化叙事与 IP 辅助。  
可借鉴：插画、IP、装饰、世界观。  
注意：官网标注 CC0，但本项目仍应筛选适合的品类气质。

**24 · 3dicons** — 3D 图标与强调性图形元素。  
可借鉴：3D、图标、视觉重点。  
注意：官网标注 CC0；传统中餐避免混入无关玩具感图标。

**25 · Anime.js** — 时间轴、元素属性、滚动与顺序动画的实现思路。  
可借鉴：JavaScript、Timeline、SVG、Motion。  
注意：需检查具体版本许可证和打包方式；优先小体积/离线。
