# 资源许可与 Cloudflare 免费静态部署检查表

## 三类来源

| 来源类型 | 可以做什么 | 不可以默认做什么 |
|---|---|---|
| 商业网站灵感库：Minimal/Kage/Refero 等 | 观察排版、节奏、色彩关系、故事组织 | 复制原网站图片、品牌名、Logo、代码或素材 |
| 代码组件库：Uiverse、MicroKit、shadcn、Motion 等 | 查看代码及授权，按项目重写或合法集成 | 不检查依赖就声称直接兼容独立 HTML |
| 插画/字体库：Kitbitz、3dicons、乔木字库 | 逐项核实许可后使用特定资源 | 把任意字体都当成可随产品转发；把第三方标识当自己的 |

## 本轮能确认的部分

- Uiverse 官网声明 UI 元素采用 MIT License；重用时保留原许可要求。
- MicroKit 官网 FAQ 声明代码为 MIT；部分组件有 React / lucide-react 依赖。
- Kitbitz 官网搜索结果标注插画为 CC0；实际下载具体文件仍查看资源条款。
- 3dicons 官网声明当前版图标 CC0，个人和商业项目可用。
- 乔木字库 README 说明仓库默认 34 款以 SIL OFL 1.1 打包；要特别注意保留字体名和修改、子集化规则。
- Motion Primitives 免费开放的核心版与收费 Pro 版区分，Pro 不应当成免费素材。
- Jiro 中部分内容为 Premium，不得假定所有提示词及模板免费。
- Liquid Glass 本次未核实，**仅保留链接与概念标签**。

## 静态项目上线前必须检查

- [ ] 根目录 `index.html`；多门店 `slug/index.html`，目录链接与相对路径完整。
- [ ] 首屏产品图片、Logo、标题字等**关键素材同域存储**，不依赖 Google Fonts/GitHub/CDN 实时连通。
- [ ] 按手机、平板、桌面宽度（360 / 390 / 768 / 1440）渲染，无白底裸 HTML、断图、裁切失误、不可操作按钮。
- [ ] 字体家族数尽量少；中文字体缺字时优雅 fallback；保留 OFL/许可证文本。
- [ ] 所有动画有无动效 fallback，尊重 `prefers-reduced-motion`。
- [ ] UI 操作真实反馈，但静态站不假装已经完成支付、预约或会员登录。
- [ ] 未使用后端构建的代码必须是浏览器可直接执行的 HTML/CSS/JS；React 源码须先构建成静态产物。
- [ ] 总站上传完整 ZIP 前保留所有已发布店铺；若要下架，须从目录和对应文件夹两处处理。
- [ ] 登陆 Pages 发布新版后，确认主页和门店路径、微信/抖音内置浏览器及国内运营商实测。
