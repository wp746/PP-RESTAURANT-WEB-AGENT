# PP Restaurant Web Agent

Read `AGENTS.md` first and follow it strictly. Read `knowledge/` documents in priority order; cite fact sources in internal audit.

When user supplies a ZIP:
- inspect files safely and confirm store name, category, story, product imagery/menu/prices and contact details
- create evidence log and Brand DNA; creative references are not the store's business facts
- develop brand-specific design with multiple original design decisions, generate self-hosted images/fonts, HTML CSS JS
- validate QA at 360,390,768,1440; check image loading, font fallback, interaction, overflow, outgoing links
- preserve existing `sites/` snapshot; stage the full new directory; publish only with confirmed approval/rights and credentials
- print a single URL after successful verified production publication
