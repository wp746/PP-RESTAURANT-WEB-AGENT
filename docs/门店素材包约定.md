# PP 门店素材包（真实项目）

在 ZIP 根目录放入 `merchant.yaml`（或 `merchant.json`），并按清单加入各类图片、表格和文字。可以包含 `docx`、`xlsx`、`pdf`、`txt`、`md`、`csv`。纯文字尽量使用 UTF-8。

```text
旺角肥肠鸡_素材.zip
├── merchant.yaml          # 重要：真实数据、商家批准状态
├── 01_品牌资料/老板讲述.txt
├── 02_门店门头/门头正面.jpg
├── 03_环境/大厅.jpg
├── 03_环境/卡座.jpg
├── 04_产品/招牌肥肠鸡.jpg
├── 04_产品/配菜.jpg
├── 05_菜单与价格/最新菜单.xlsx
└── 06_授权确认/授权说明.txt
```

关键字段：店名 `name`、品类 `category`。强烈建议提供 `address`、`phone`、`opening_hours`、`menu`、招牌菜、品牌事实、目标客群、真实授权素材。

**上线闸门**：
- `approved_for_publication: true` 只在老板实际确认具体网页事实与宣传文案后填写；不能自动代签。
- `media_rights_confirmed: true` 只在老板确认照片和商标可用于公开网页后填写。
- 缺失资料只能用于内部预览，不能用 AI 编造历史、价格、联系电话或者照片。
- 文档内写“演示”“概念”的内容不能未经确认就作为事实发布。

ZIP 不应包含：身份证、密码、微信登录状态、API Token、私人客户名单、隐私医疗信息。未经授权不要上传他人的商用图片。
